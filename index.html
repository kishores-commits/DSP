01 About this course

45 lecture hours · 30 practical hours

This course introduces data structures from the ground up using Python. Students progress from arrays and linked lists to stacks, queues, trees, and finally graphs, searching, and sorting. Each topic is paired with a practical implementation so the theory stays grounded in actual coding practice.

03 Lecture notes

Syllabus checkpoints

Unit I · Structures

Foundations
  • Algorithm design paradigms
  • Linear vs. non-linear data structures
  • Python built-ins: lists, tuples, dictionaries, sets
  • Comprehensions and strings
Arrays
  • Operations, applications, and limitations
  • Lists and pointer-based structures
Singly linked list
  • Node structure
  • Append, size, traversal, delete, search, clear
Doubly & circular linked lists
  • Doubly linked structure and operations
  • Circular list traversal and deletion

Unit II · Stacks, Queues & Trees

Stacks
  • Push, pop, peek
  • Bracket matching and expression evaluation
Queues
  • Queue design
  • Enqueue and dequeue operations
  • Real-world queue use cases
Trees
  • Binary trees and BST operations
  • Inorder, preorder, postorder traversals
  • Expression trees and balancing

Unit III · Graphs, Searching & Sorting

Graphs
  • Directed, undirected, weighted graphs
  • Adjacency list vs. adjacency matrix
  • DFS and BFS traversal
Searching
  • Linear search
  • Binary search
Sorting
  • Bubble, insertion, selection, quick, heap sort
