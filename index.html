01 About this course

45 lecture hours · 30 practical hours

This course builds data structures from first principles in Python — starting with arrays and linked lists, moving through stacks, queues, and trees, and finishing with graphs, searching, and sorting. Each unit pairs its theory with hands-on practicals so every structure gets implemented, not just described.

02 Units at a glance

03 Set up in VS Code

Clone this repository, open it in VS Code, and write each practical inside its matching file under code/ — for example code/prac05_stack.py. Every file already has the function signatures and a short docstring from the lab sheet, so you only need to fill in the logic. Commit and push, and this page (served from the main branch via GitHub Pages) will link straight to whatever you've written.
